# ADR-003: Graph implementation remains the current SVG view

**Status:** Interim decision, 2026-10-20; revisit at Milestone 6

The workbench retains its React SVG graph. React Flow and ELK from the visual-language plan are not installed and their behavior is not claimed. Evaluate them against the 300-node performance and keyboard/table parity gates before replacing the current view. Manual positions, if added, must stay outside canon.
